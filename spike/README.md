## 個人情報・認証情報のリスク

- 拡張はcookies API、localStorage、パスワードDB、リクエストヘッダーを読み出さない。しかしMHTMLが秘密情報を含まない保証にはならない。
- 表示された氏名・アバター・メール、位置表示、検索語、リンクやリソースURL内の識別子、非表示DOMや埋込データが残る可能性がある。メタデータにも完全なURL・検索語が入る。
- Cookieストア全体のエクスポートとMHTML保存は別機能。Cookie/Set-Cookie/Authorizationヘッダー風文字列とトークン名の検査は兆候検出だけであり、認証秘密の不在証明にはならない。画像内個人情報はこのスクリプトで検出しない。
- 解析はローカルで、HTMLやスクリプトを実行せず、リンク先や外部リソースを取得しない。出力テキストとJSONも個人情報を引き継ぐ可能性があるので公開・Git登録しない。
- 保存APIによるキャプチャ中にChrome自身が追加リソースを取得しないことまでは保証できない。スクリプトは検索リクエストや再読込を発行しない。
- ポップアップを閉じると途中終了し得る。2ファイルは原子的保存ではなく、部分成功がある。一回制限はポップアップ内のみ。全体の実装ではない。
